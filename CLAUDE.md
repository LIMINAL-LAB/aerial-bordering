# CLAUDE.md

## Project

**aerial-bordering** is a React web application presenting an investigative report about Frontex's aerial surveillance operations in the Mediterranean and their impact on migrant rights. The app is structured as a document-style viewer with detailed academic citations and interactive footnote navigation.

**Source structure:**
- `src/components/` — pages `HomePage`, `ReportPage`, `DatabasePage`, `MethodologyPage`, plus shared components such as `NavigationBar` and `ContentSection`
- `src/store/` — shared state (zustand)
- `src/data/` — report and case data (mostly generated, see below)
- `public/` — static assets: `logo-erc.png`, `Pixel_sky_Loop1.mp4` (home-page background video), `pattern-media/` (photos, videos and PDFs per incident date, referenced from `src/data/violations.json`), `report-images/` (webp report figures) and `downloads/` (report PDF, data-analysis PDF and JORA/Irini datasets linked from the Report and Methodology pages)
- `build/` — Output dir (gitignored)

## Development Commands

```bash
npm run dev     # or: just dev      — start dev server (assume already running, never start yourself)
npm run build   # or: just build  — production build
npm run test    # NEVER run — waste of compute, no tests configured
just port-report <docx>          # regenerate src/data/report.json from a Word draft
```

`just port-report` takes the path of the report draft to port (drafts are kept in the untracked
`design/` folder). `src/data/report.json` is generated by that recipe —
hand edits are lost on the next port, so change the source docx instead. `src/data/irini.json`
is likewise generated, by the `frontex-data` pipeline (`just app` there), alongside
`src/data/app_data_all.json`.

## Architecture

- **SPA** with React Router DOM for client-side routing
- **Four routes:** `/` `HomePage` (investigation highlights), `/report` `ReportPage` (document viewer), `/database` `DatabasePage`, `/methodology` `MethodologyPage`
- **Key components:** `NavigationBar`, `ContentSection` (highlighted text blocks), `ReportPage` (sticky nav, footnotes, PDF download button, scroll management)
- Dynamic sticky positioning, interactive bidirectional footnotes, custom scroll management with offset calculations
- **`src/data/app_data_all.json` and `src/data/violations.json` are generated**, in the sibling
  repo `../frontex-data` (`just violations`, `just adsb && just merge`). Do
  not hand-edit them — the next regeneration silently drops the edit.

## Deployment

- **Netlify** via `netlify.toml`; build command: `npm run build`; publish dir: `build`
- SPA fallback routing configured for client-side routing
- `VITE_SITE_PASSWORD` (see `.env.example`) enables the client-side password gate; leave it unset for a public site
