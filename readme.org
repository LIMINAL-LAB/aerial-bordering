* Aerial Bordering

An interactive investigation into Frontex's aerial surveillance in the Central Mediterranean, with a report, a database of cases and a methodology.

** Development

=nix= and =direnv= provide Node (or install Node 22 yourself). Then run =npm install= and =npm run dev=. =npm run build= builds the site to =build/=.

** Configuration

=VITE_SITE_PASSWORD= (optional) enables a client-side password gate; see =.env.example=. Leave it unset for a public site.

** Data

=src/data/app_data_all.json=, =src/data/violations.json= and =src/data/irini.json= are generated by the =frontex-data= pipeline. =src/data/report.json= is generated by =just port-report <docx>=. Do not hand-edit any of them; the next regeneration drops the edit.

** Deployment

Netlify, configured in =netlify.toml=.
